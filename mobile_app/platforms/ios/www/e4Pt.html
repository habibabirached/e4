  2. E4 Point Procedure – High Level Overview
    1. Pre Set-Up – tool inspection, verify GT assembly configuration. Full procedure can be found in Section 5.4
      The upper GT cases are installed and fully torqued – All cases must be installed and tensioned including the mini-case.
    2. Set up base station
    3. See FRD-T-0507-01 for full Casing plug removal procedure
    4. Remove all clearance hole plugs, including inner casing plugs and clean area around plug hole to ensure no debris, anti-seize or corrosion is on the flat surface the stand off/spacer attaches too. This will ensure proper magnetic mating of the stand offs and accurate measurements. Any Debris between the stand off and casing will directly affect the measurement accuracy.
      For Opening Clearances it is required that the clearance probe holes are cleaned of corrosion prior to rotating the rotor. Cleaning may require a bottle brush, air, and in extreme corrosion instances a drill per FE/TFA discretion.
    5. Ensure rotor is on Turning gear or otherwise rotating with Lift Oil if required. Obtain shaft RPM. A smooth rotor rotation is required, system is designed to work with a rotor rotation between 0.5 and 15 RPM
      1. Shaft RPM can be determined manually, from Customer Control Room, or via TRACC scan app (FRD-T-2017-1055)
      2. If determining RPM via the app a manual verification of RPM is also needed
    6. Install stage and frame specific spacer into clearance probe holes and verify NO sensor interference with turbine blades by inserting the dummy probe while rotor is rotating..
      1. Dummy Probe should be slightly longer (0.25”-0.33”) than the actual sensor and whole. Do not use a broken dummy probe. Intact probe will have hole features on the end of the probe
      2. See Figure 15 Dummy Probe Length Check with Sensor for example of whole Dummy Probe compared to Sensor.
      3. Ensure rotor rotates through multiple airfoils before removing dummy probe to ensure no interference with the turbine blades

      Dummy Probe Length Check with Sensor

      WARNING!

      Failure to check gross clearance with the Dummy Probe can result in sensor decapitation and FOD introduction to the turbine.
    7. Install sensor into spacer
    8. Follow e4 Point App process for measuring a turbine for specific stage and location
    9. See section 5.4 for pre-set up and use instructions
    10. When data has been recorded for current location, measurement can then be performed at next location on the same stage by performing the above procedure from step 5.2.5
    11. When all locations for current stage have been measured repeat procedure for next stage starting with step 5.2.5
      The correct spacer must be used for each stage and location. Failure to use correct spacer can cause sensor decapitation, FOD introduction to the turbine, or failure to accurately measure clearances
    12. When all stages and locations have been measured load all raw data files to GE Vernova Box using “Export” button as shown in Figure 29 and section 6.2
    13. Generate the customer report and load to GE Vernova Box and send to customer if applicable using “Report” button as shown in Figure 29 and section 6.2
    14. Disassemble tool and package back into appropriate containers

  1. Gas Turbine Setup
    1. The upper GT cases are installed and fully torqued – All cases must be installed and tensioned including the mini-case.
    2. All Clearance probe plugs are removed and surfaces cleaned, including inner compressor case/Double Wall Casing Plugs.
      See FRD-T-0507-01 (Inner Compressor Case Plug Removal and Rotor Rim Checks) for more details
  2. The Compressor Clearance measurement kits are equipped with everything needed to perform manual measurements (drop check) of the Compressor Airfoil clearances through the 6 point/4 point holes, with the exception of basic hand tools and precision measurement equipment
    1. If manual checks are required due to an error in the app or with the hardware an ER case must be entered and the Outage Tooling Team informed
  3. To begin Compressor Clearance Measurement on a Single Wall Compressor
    1. Determine appropriate clearance hole plug to be removed. These plugs are denoted with “CP” stamped on the Casing next to a number that represents the Casing thickness
      Square Outer Casing Clearance plug with “CP” stamped on the case

    2. Each Clearance Probe hole is plugged to prevent dirt and debris from entering the turbine. For single wall casings this plug can simply be removed.
      Care should be taken to mark the plugs with each location or replace the plug immediately after measurement to avoid accidental installation of an incorrect plug.
  4. To begin Measurements on a double walled Compressor
    1. Double walled compressor measurements require the removal of the outer casing clearance plug as well as the inner casing clearance plug
      Inner Compressor Casing plug. Shown with Outer case removed and Casing Thickness Stamped

    2. Removal of the outer casing plug is the same as with single walled compressors. See FRD-T-0507 for more complete guidance.
      Note – Using a 12 point socket on larger/square plugs has been found useful See Figure 16: Square Outer Casing Clearance plug with “CP” stamped on the case. 12 point socket should be used on square end to prevent the need for thin walled hex socket
    3. Removal of the inner Compressor Casing plugs requires use of the 100F0017F0036, 610-11-00-62, or 305T6365, as determined by the frame size
      Note - The inner casing plug has an internal reversed threaded hole as well as an external socket to remove the plug. Both components must be used to ensure a successful completion. See Figure 17 Inner Compressor Casing plug. Shown with Outer case removed and Casing Thickness Stamped
    4. To use the inner casing plug removal tools see FRD-T-0507-01
      Caution: Do not use left hand threaded tool as slide hammer. The threaded portion will break.
  5. Lift oil and turning gear
    1. The rotor will need to be turned between 0.5 -15 RPM using the turning gear or some other method that will turn the rotor at a constant speed. (Some sites have used an air motor attached to the manual input on the turning gear.)
    2. The rotor will also need to be on lift oil.
      Some sites do not have lift oil; in this case, consult the MLI 0404 for that target without lift oil. (nearly every site will use lift oil, currently only a few early 7HA01 sites do not have lift oil)
  6. E4 point Tool Inspection
    1. Verify all the parts listed above in Figure 14 : Controller Box Components are in the kit and appear to be in good condition.
    2. Only spacers for desired frame will be included in shipped kit.
      See Table 1 Kit and spacer applicability for more details.
    3. Dark Reference cap should fit snuggly over sensor tip. And be tethered to the sensor top hat
    4. Operational Check cylinder fixture should be clear of debris or blockages.

      1. Broken or cracked magnet must be removed prior to use to avoid FOD introduction into turbine
      2. Loss or removal of a magnet will necessitate steady manual holding of the spacer and probe to properly collect data

  6. Figures below Discrete Double Counting is a more common phenomenon that occurs over all frame sizes.

    Discrete Double Counting

    1. Discrete double counting occurs for a variety of reasons, if no more than 1/8 of airfoils measured exhibit discreet double counting on the airfoil tip (See the bottom plot in Figure 47 Discrete Double Counting) the maximum clearance error has been calculated to be ~10-13%.
    2. Pervasive double counting (See the top plot of Figure 47 Discrete Double Counting) and clear shelf double counting (See Figure 46 Clear Double Counting) is not allowed. Analysis must be re-run. If it persists perform manual check and submit ER case
    3. Discreet Double Counting can be diagnosed by close inspection of the clearance plot. Darker clearance dots indicate multiple clearance values in close proximity to each other.
    4. In Figure 47 Discrete Double Counting the top plot shows pervasive double counting in that a majority of airfoils have overlapping clearance values. This data is unacceptable and should be re-run
    5. The lower plot shows an acceptable discreet double counting event around index 5000 on the X axis. Discreet double counting is easily identified by a darker clearance circle
    6. To address double counting in all forms
      1. Manually determine rotor RPM and compare this value to what the app is calculating. If there is a major discrepancy use manual RPM
      2. Verify, in Figure 44 App Settings, that the Points Between Blades is set to Automatic, Points per blade is set to 8, and minimum points is set to 2. Note, these settings should not be manipulated and will be password controlled
    7. If double counting can not be resolved manual clearances must be taken and the Outage Tooling team contacted. Be prepared to pass along any run and clearance data for analysis, as well as Final save data

  9. Data Post Processing
    1. The collected data is filtered to remove anomalies created by the leading and trailing edges of the airfoil. The data is then filtered to ensure that only the squealer tip (if applicable) is measured for averaging. If no squealer tip is present on the airfoil (determined programmatically) the tip measurements are collected as is.
    2. The data is then averaged over each airfoil to obtain the measured displacement from the sensor tip. This displacement is then run through a calculation to determine the actual clearance between the casing and airfoil.
    3. In the event that there are concerns about the measurements, or if the measurements are questionable it is possible to post process the data using alternate methods
    4. Please contact the Outage Tooling Team David.Runkel@ge.com to perform this post processing. Include the box link to where your data is stored and a description of your issue

    2. Manufacturers recommended warm up time is 60 minutes. Per GE Vernova testing it has been found that a warmup time of 10 minutes is adequate to maintain tool accuracy.

  • Typical Connectivity and Operation Errors
    Issue Solution
    Serial connection indicator is not green on initial start up or connection error message
    1. Open Main Menu. This will initiate app communication through the serial port.

    1. Environmental use and Cleaning Instructions:
      1. The base station, sensor, and cabling are NOT considered submergible or waterproof. To clean the external features and spacers, use a lint free cloth dampened with water or light duty general purpose cleaner. Wipe residue free and wipe excess liquid. Do not close lid to case before surfaces are dry.
      2. Dry Cleaning: wipe the face of the sensor lens with an optics anti-static lint-free brush or cloth or blow with dehumidified, clean, oil-free compressed air.
      3. Wet Cleaning: Use a clean soft, lint-free cloth or lens cleaning paper with pure alcohol (isopropyl)

    1. Pre Set-Up – tool inspection, verify GT assembly configuration.
    2. Set up base station.
    3. Remove all clearance hole plugs, including inner casing plugs and clean area around plug hole to ensure proper magnetic mating and FOD prevention into turbine.
    4. Ensure rotor is on Turning gear or otherwise rotating with Lift Oil if required. Note shaft RPM.
    5. Install stage and frame specific spacer into clearance probe holes and verify NO sensor interference with turbine blades by inserting the dummy sensor probe. Ensure rotor rotates through multiple airfoils before removing dummy sensor probe to ensure no interference with the turbine blades.
    6. Failure to check gross clearance with the Dummy Sensor Probe can result in sensor decapitation and FOD introduction to the turbine.
    7. Install sensor into spacer.
    8. Follow e4 Point App process for measuring a turbine for specific stage and location.
    9. When data has been recorded for current location, measurement can then be performed at next location on the same stageby performing the above procedure from step 5 above.
    10. When all locations for current stage have been measured repeat procedure for next stage starting with step 5 above.
      1. The correct spacer must be used for each stage. Failure to use correct spacer can cause sensor decapitation, FOD introduction to the turbine, or failure to accurately measure clearances.
    11. When all stages and locations have been measured load all raw data files to GE Box.
    12. Generate the customer report and load to GE box and send to customer if applicable.
    13. Disassemble tool and package back into appropriate containers.

      1. Verify all the parts listed above are in the kit and appear to be in good condition. Only spacers for desired frame will be included in shipped kit. Dark Reference cap should fit snuggly over sensor tip. Fixture should be clear of debris or blockages. The magnets should not be cracked or broken on either the sensor or spacers
      2. Electrical and sensor connections should be clear of debris.
    2. System Test
      1. Follow the procedure in the E4 Point Procedure section to set up the unit and verify connectivity with the sensor.
      2. An iPad or iPhone with GE mobile Iron installed is required in order to install the e4Point tool from the GE Apps Store.
    3. Gas Turbine Setup
      1. The upper GT cases are installed and fully torqued - All cases must be installed and tensioned including the mini-case.
      2. All Clearance probe plugs are removes and surfaces cleaned, including inner compressor case/Double Wall Casing Plugs.
    4. Lift oil and turning gear
      1. The rotor will need to be turned between 0.5 -15 RPM using the turning gear or some other method that will turn the rotor at a constant speed. (Some sites have used an air motor attached to the manual input on the turning gear.)
      2. The rotor will also need to be on lift oil.
        1. (Note that it is possible that the measurement of the rotor lift due to lift oil will be needed and the deviation will need to be included on the alignment diagram.)
        2. Some sites do not have lift oil; in this case, consult the MLI 0404 for that target without lift oil. (nearly every site will use lift oil, currently only a few early 7HA01 sites do not have lift oil)

    1. Download the “e4 Point” app from the GE app store to a GE iPad or iPhone.
    2. Connect the fiber optic cable to the controller. Connect the RedPark power Cable to the Redpark Power supply on the Base Station and the RedPark Serial Adapter to the controller. Connect Base station power supply cable to the Base Station and to a 120V power source.
    3. Position the base station near the gas turbine compressor section. Keep in mind that the sensor cable, Redpark Cables, and Power Cables constitute a tripping hazard. Care should be made to position the base station close to the compressor casing. Additionally, the Fiber Optic cable has a 3x maximum radius and should never be kinked.
    4. Power on the Base station (120/220 Vac, 50/60Hz). An adaptor may be needed. Turn the base station on by flipping the single rocker switch.

    6. Sensor and controller warmup time is 5 minutes. Measurement prior to 30 minute warm up period will result in erroneous dark reference, operability check, and clearance data.
      1. Good practice is to set up and turn on the e4 point tool and then remove clearance hole plugs and note casing thicknesses. While this may not take full 30 minutes, it will reduce idle time.
    7. Once 30 minute warm up time has elapsed open the Menu page and select “Sensor Setup” Submenu.
    8. Ensure the dark refence cap is snuggly fit over the end of the sensor and then select the “Dark reference” submenu. Follow the on-screen instructions to perform dark-referencing of the sensor.
    9. Remove dark reference cap from sensor. Clean the sensor mating surfaces and lens as directed above and carefully insert the sensor into the fixture.
    10. Select “Sensor Operability Check” from the submenu and follow on screen instructions for checking the sensor. When this has been completed there will be a popup indicating whether or not the sensor is ready to use.
    11. Verify that sensor mastering is acceptable by navigating to the main menu and selecting the “Get Data” submenu. Collect data for a short amount of time with the sensor probe still placed in the fixture. The display should be a constant line at 15mm.
    12. The sensor is now ready to use. Do not turn power off until all measurements are complete, data has been saved to GE Box, and a Customer report has been generated.

      Set Sensor Probe Dark Reference

      Dark referencing smooths out the signal output because it acquires the sensor brightness at this specific point in time. It is critical the sensor be covered with a cap and in a fully dark pocket. This step is needed every time the tool is plugged in or power cycled, or if the data is showing noise. If the dark reference fails, it is likely the sensor or connection is contaminated.

      The system requires a warm-up time of approximately 30 minutes prior to setting the dark reference. Please ensure that the system has been powered on for 30 minutes to ensure it is warmed up.

      1. Cover the sensor with the sensor cap to ensure that nothing is in the measurement range and no ambient light enters the sensor.
      2. Press the Start Dark Reference button to initiate the process.

      The indicator light will flash yellow, then red. After <30 seconds, this page will disappear and you should see a flat line displayed indicating a successful dark reference.
